# 🤖 AI Resume Screening & Job Matching System

## Project Overview

AI Resume Screening & Job Matching System is a Machine Learning based application that automatically analyzes candidate resumes and recommends the most suitable job role.

The system uses Natural Language Processing (NLP) techniques to convert resume text into machine-readable features and applies Machine Learning algorithms for job category prediction.

---

## Objectives

- Automate resume screening process
- Analyze candidate skills and experience
- Predict suitable job roles
- Generate resume matching score
- Reduce manual resume filtering time

---

## Features

- Resume Text Analysis  
- Job Role Prediction  
- TF-IDF Text Feature Extraction  
- Machine Learning Classification  
- Matching Score Generation  
- Streamlit Interactive Web Application

Resume Dataset | ↓ Data Preprocessing | ↓ TF-IDF Feature Extraction | ↓ Machine Learning Model Training | ↓ Resume Prediction | ↓ Recommended Job Role + Matching Score
